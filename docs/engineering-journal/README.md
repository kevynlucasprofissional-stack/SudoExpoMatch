# Engineering Journal

## Purpose
Memória durável de investigação, decisões, testes e protocolo anti-repetição da arquitetura do SudoExpo Match.

## Read-before-work rule
Antes de investigar ou modificar qualquer área, pesquise `CURRENT.md` por componentes, decisões e hipóteses testadas.

## Anti-repeat rule
Não repita um experimento conclusivo a menos que uma premissa, versão ou código relevante tenha mudado.
